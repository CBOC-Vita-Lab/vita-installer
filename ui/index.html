Connect your Vita

Wi-Fi recommended

On the Vita open VitaShell and press SELECT. Keep both on the same Wi-Fi. With Vita Companion installed it works even without VitaShell open, and games can be started from here.

USB or memory card fastest for big games

In VitaShell press START, set SELECT button to USB, connect the cable and press SELECT. Or put the Vita's memory card in a card reader. It is found automatically.
