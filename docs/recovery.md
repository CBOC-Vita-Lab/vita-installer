# Recovery

Reconnect the same Vita or card, then choose **Resume**. Verified files are
kept; an interrupted file starts again. A different device or missing job
marker stops recovery rather than guessing where to write.

If a source file was deleted or moved, restore it and resume, or choose
**Choose files again** to select a complete replacement. Changed files must
pass a fresh check. The app will not install an incomplete package.

**Cancel** stops transfer and keeps the recovery record. It does not remove
games, saves or unrelated files. An uncertain installation result must be
checked before another installation attempt.

Existing files are kept unless an exact replacement was explicitly selected.
Replacing a RetroFlow cover creates a verified local backup and retains the
old cover in the job folder on the Vita/card. A disconnect between moves can
temporarily leave the cover absent; Resume uses the retained backup and staged
image to finish without discarding the old copy.

The journal and backups stay on this computer. They are not uploaded.
An update cannot proceed if saved state or the installed app changed after
the check, or a backup cannot be verified.
