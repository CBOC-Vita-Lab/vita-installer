# Galaxy

The `thp48d` source and preparation files are available privately, but the
matching final `SMGV00001` VPK has not been established. The installer detects
`Galaxy-thp48d-desktop-held.zip` and keeps installation disabled. It will not
substitute an older development package.

Keep the current Vita installation. Use the same
[CBOC Vita Installer](https://github.com/CBOC-Vita-Lab/vita-installer/releases)
when a verified matching bundle becomes available in the
[Galaxy repository](https://github.com/CBOC-Vita-Lab/galaxy-vita/releases).

The full recovered cooker is retained, including movies and audio. Game data,
proprietary modules and private artwork are not supplied by the installer.
