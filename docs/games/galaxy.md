# Galaxy

The installed `SMGV00001` runtime is verified as `thp48d`. The installer still
keeps Galaxy disabled while the complete media-preparation recipe is verified.
It will not substitute an older package or unoptimized movies.

Keep the current Vita installation. Use the same
[CBOC Vita Installer](https://github.com/CBOC-Vita-Lab/vita-installer/releases)
when a verified matching bundle becomes available in the
[Galaxy repository](https://github.com/CBOC-Vita-Lab/galaxy-vita/releases).

The supported input is your own USA Rev 0 game (RMGE01), as an ISO/RVZ or full
extraction. Preparation runs on the computer, including the separate movie
optimization, before any files reach the Vita. Players will not need Python
or Dolphin. Game data, proprietary modules and private artwork are not bundled.
