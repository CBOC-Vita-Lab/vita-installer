# Infected

**No downloadable desktop install bundle yet.** The release ZIP contains
source and guides only. It cannot be selected as a finished game bundle.
For a new owner, use [Building](https://github.com/CBOC-Vita-Lab/infected-vita/blob/main/BUILDING.md) with your own disc, then follow
[Manual installation](https://github.com/CBOC-Vita-Lab/infected-vita/blob/main/INSTALL.md).

The steps below apply only if you already have the original owner's local
`Infected-current-desktop-private.zip`. That package is not uploaded because
it includes translated game code and private artwork.

Requires a homebrew-enabled Vita, VitaShell, your own **USA v1.02
(`ULUS-10054`)** ISO, and a legitimately obtained `libshacccg.suprx`.

1. Open [CBOC Vita Installer](https://github.com/CBOC-Vita-Lab/vita-installer/releases) and connect your Vita.
2. Select your existing local `Infected-current-desktop-private.zip`.
3. Select your ISO. Add the shader compiler only if prompted.
4. Keep the default artwork or select your own, then click **Install**.

Leave that local install ZIP zipped; the installer opens it. Do not substitute
the source ZIP from GitHub, an ISO alone or a different runtime.

No Python or manual extraction is needed. The app shows the required space
and any final VitaShell action. Existing saves, settings and texture packs
are protected.

Keep the computer and Vita awake through preparation, copying and checks.
If disconnected, reconnect the same Vita and choose **Resume**.

For compatible updates, choose **Update app** to skip ISO preparation and keep
verified game data. It requires the completed install receipt on the same
computer and Vita. Missing or changed data requires **Full setup**. An update
still needs your confirmation; matching files are not recopied.

HD textures are optional, not required. HDCube permission is still pending;
its files are not bundled. A compatible Vita texture pack can be added later
using the game's texture guide. Approved packs can be included once permission
and compatibility are verified.

This private package retains installed artwork that is not cleared for public
redistribution. It is for the original owner's use, not a public download.
